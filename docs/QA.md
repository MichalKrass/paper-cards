- 短内容样例：在打印媒体下正文与关键指标可见，导航和操作按钮隐藏。

- 结构检查：4 页均为 595×841.9 pt；PDF 头正确；包含 5 个链接注释；来源 URL 存在。
- 视觉检查：使用 Poppler 以 120 DPI 渲染全部 4 页并逐页查看。
- 首轮发现：页面出现了屏幕阅读器跳转按钮，论文 ID 与标题局部重叠。
- 修正复检：隐藏仅供屏幕使用的元素后重新生成并渲染；首尾页、分页边界、中文、指标表格、判断网格和长 URL 均正常。
- 说明：中文视觉渲染正确；`pypdf` 对浏览器嵌入的中文字体文本层解码不可靠，因此中文验收以 Poppler 渲染结果为准。
